# Cityland Mall Tenant Portal

Public page for tenants to send store details, offers and events to the marketing team. English and Arabic.

This repository holds only the page. Tenant data is stored in the mall's own Google Sheet and Drive, never here.
Do not add spreadsheets, tenant lists or backend code with email addresses to this repository.

Set `ENDPOINT` near the bottom of `index.html` to the Apps Script web app URL, and optionally `TURNSTILE_SITEKEY`.
